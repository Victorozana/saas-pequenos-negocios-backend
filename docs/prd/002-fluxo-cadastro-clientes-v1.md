O QUÊ, PRA QUEM, POR QUÊ?

Este PRD documenta, o cadastro de clientes do projeto. O cliente primário, o que contratará software para vender para os seus próprios consumidores, marmitas, almoços etc. Clientes primários são restaurantes.

Estamos documentando porque é necessário separar os fluxos e métodos de cadastro dos dois tipos de clientes. Agora desenvolveremos o cadastro dos restaurantes (conhecidos também como tenants), os clientes dos restaurantes serão cadastrados em outro fluxo e outro PRD irá documentar as decisões particulares a eles.

Todo cliente é um restaurante, um mercado, mercearia ou padaria.
A necessidade deles é ter um método de expor seus produtos, para se cadastrarem entrarão no site, encontrarão o cadastro, e seguirão um fluxo definido posteriormente em um RFC com o mesmo código deste PRD.

Todo restaurante obrigatoriamente deve ser uma pessoa jurídica e possuir CNPJ.
